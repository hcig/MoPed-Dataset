# MoPed-Dataset
MoPed (Motion-Capture Pedestrians for Simulated Environments) offers high-fidelity motion capture data of pedestrians crossing roads in controlled conditions with diverse weather and object-carrying variations. Aimed at improving ecological validity in automated vehicle testing and pedestrian modeling.

---

## Dataset Overview

- **Participants:** 11 (diverse in age, gender, and body type)
- **Total recordings:** 220 motion capture sequences
- **Scenario:** Pedestrian street crossings on a two-lane urban road
- **Weather conditions:** Dry, Simulated Rain
- **Carried objects:**
  - None
  - Umbrella
  - Smartphone (reading message)
  - Suitcase (rolling)
  - Box (held in arms)
  - Combinations (e.g., umbrella + suitcase)

---

## Data Collection Setup

- **Location:** Outdoor test track (EuroNCAP protocol compliant)
- **Motion Capture System:** [Xsens MVN Link](https://www.movella.com/products/motion-capture-suits#hardware)
- **Weather Simulation:** Mobile rain sprinkler system (0.5–4 mm/h)
- **Gait Measures Captured:**
  - Walking Speed (m/s)
  - Cadence (steps/min)
  - Step Length (cm)
